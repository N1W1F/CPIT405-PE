Chapter 1 · Internet & Web · Slides 21–22

What is the difference between GET and POST? What do PUT, PATCH, and DELETE do?

Show answer and explanation

GET retrieves a resource. Parameters commonly appear in the URL query; it should not change server state. POST submits data, usually in the request body, commonly to create a resource or trigger an action. Do not put passwords in a GET query string.

PUT replaces a resource, PATCH changes part of one, and DELETE removes one. The server decides the exact behavior of each endpoint. GET is safe and idempotent; PUT and DELETE are intended to be idempotent; POST usually is not.

Chapter 1 · Internet & Web · Slides 19–20

What is the difference between a URI and a URL? Identify the parts of a URL.

Show answer and explanation

A URI identifies a resource. A URL is a URI that also tells you where or how to access it. Therefore every URL is a URI, but not every URI is a URL.

For https://example.com:443/courses/web.html?level=4&lang=en#topics: https is the scheme/protocol; example.com is the domain/host; 443 is the port; /courses/web.html is the path; level=4&lang=en is the query string; topics is the fragment. The ? starts the query, & separates parameters, and # starts the fragment. The default HTTPS port is 443, so it may be omitted.

Chapter 4 · JavaScript · Slides 26–27

How do JavaScript operator groups differ? Explain =, ==, and ===.

Show answer and explanation

Arithmetic operators (+, -, *, /, %, **) calculate values. Assignment operators (=, +=) store or update values. Comparison operators (>, <, >=, <=, ==, ===, !=, !==) return booleans. Logical operators (&&, ||, !) combine or negate conditions. ++ increases a variable by one, and -- decreases it by one. typeof reports a value's type as a string.

= assigns: a = 5. == compares after possible type conversion, so 5 == "5" is true. === compares without that conversion, so 5 === "5" is false. != and !== are their inequality counterparts. The doctor may give values and ask you to calculate the output.

Chapter 1 · Internet & Web

Chapter 1 · Internet & Web · Slides 9, 12

What is the difference between the Internet and the Web?

Show answer and explanation

The Internet is the global network that connects devices and carries data using agreed protocols. The Web is one service that runs on it: linked pages and resources accessed with a browser, usually through HTTP or HTTPS. Email also uses the Internet, but email is not the Web.

Chapter 1 · Internet & Web · Slides 17, 23–24

What is HTTP, and what is in a request and response?

Show answer and explanation

HTTP is the protocol that lets a client request a resource and a server return a response. A request has a method and target, headers, and sometimes a body. A response has a status code, headers, and often a body containing the returned content.

Headers carry metadata, such as Content-Type or authorization. The body carries the actual data, such as JSON sent in a POST request or HTML returned by the server. A GET request usually has no body.

Chapter 1 · Internet & Web · Slides 25–28

What do the HTTP response status code groups and common numbers mean?

Show answer and explanation

The first digit identifies the class. 1xx means informational; 2xx means success; 3xx means redirection; 4xx means a client-side request problem; 5xx means a server-side problem. The classmate's shorthand 3**, 4**, and 5** refers to these status-code families, not JavaScript operators.

  • 200 OK: successful request with a response.
  • 201 Created: a resource was created.
  • 204 No Content: successful request with no response body.
  • 301 Moved Permanently and 302 Found: redirects.
  • 400 Bad Request: malformed request; 401 Unauthorized: authentication is needed; 403 Forbidden: access denied; 404 Not Found: no matching resource.
  • 500 Internal Server Error: generic server failure; 502 Bad Gateway: bad response from an upstream server; 503 Service Unavailable: server temporarily unavailable.
Chapter 1 · Internet & Web · Slides 31–36

Put the steps of loading a web page in order.

Show answer and explanation

The browser parses the URL, uses DNS to resolve the domain to an IP address, establishes a TCP connection, and performs TLS negotiation when the URL uses HTTPS. It sends an HTTP request; the server sends an HTTP response. The browser parses the HTML and may issue further requests for CSS, JavaScript, images, and other resources before rendering the page.

Remember the core sequence: URL → DNS → TCP → TLS (for HTTPS) → HTTP request → HTTP response → more resource requests → render.

Chapter 1 · Internet & Web · Slides 37

How does a static website differ from a dynamic website?

Show answer and explanation

A static site serves prepared files, so the same file can be returned to many visitors. A dynamic site generates or changes content based on data, user input, or application logic; it often uses a server and database. Both can use JavaScript in the browser. “Static” describes how the served content is produced, not whether the page looks interactive.

Chapter 1 · Internet & Web · Slides 38–41, 43

What are the three web application tiers, and who works on each part?

Show answer and explanation

The client/browser displays the interface and runs client-side code. The server receives requests and runs application logic. The database stores and retrieves persistent data. Frontend work focuses on the client (HTML, CSS, and browser JavaScript); backend work focuses on the server and data; full-stack work spans both.

What are HTML elements and attributes? What do common text tags mean?

Show answer and explanation

An element usually has an opening tag, content, and closing tag, such as <p>Hello</p>. Attributes in the opening tag add information or behavior, such as href in an anchor. Some elements, such as <img>, are void elements with no closing tag.

<h1> is the main heading; <p> is a paragraph; <sup> raises text, such as an exponent; <sub> lowers text, such as the 2 in H₂O; <br> creates a line break. Use the tag whose meaning fits the content.

Chapter 2 · HTML · Slides 10–13

What is the basic structure of an HTML document?

Show answer and explanation

<!DOCTYPE html> declares modern HTML. <html lang="en"> wraps the document and states its language. <head> holds metadata, the tab title, and linked resources; it is not the visible page content. <body> contains visible content. <meta charset="UTF-8"> sets character encoding, and the viewport meta tag helps pages fit mobile screens.

Chapter 2 · HTML · Slides 17–18

How do you create external, internal, email, and phone links?

Show answer and explanation

Use an anchor: <a href="destination">Visible text</a>. An external URL begins with a scheme and domain, such as https://example.com. A local file can be syllabus.html; a fragment link is #section-id; mailto:student@example.com opens an email composer; tel:+966123456789 asks a compatible device to dial.

The href value is the destination. The text between <a> and </a> is what the user sees and clicks.

What is the difference between ordered and unordered lists?

Show answer and explanation

<ol> creates an ordered, usually numbered list. <ul> creates an unordered, usually bulleted list. Each item goes in an <li> element. Put a nested <ol> or <ul> inside the relevant <li> when one item has subitems.

How does an HTML form work, and how do you fix a password field?

<form action="/login" method="post"> groups controls and submits them to /login with POST. A <label for="pwd"> connects to <input id="pwd">; those values must match. name="password" supplies the key sent to the server. type="password" visually masks the entered characters, while required asks the browser to reject an empty submission. Masking is not encryption; use HTTPS for secure transport.

Checkboxes use type="checkbox" and allow independent selections. Give controls a name when their values must be submitted.

Chapter 2 · HTML · Slides 33–36

What does iframe do, and what are block, inline, and void elements?

Show answer and explanation

<iframe src="other.html" title="Other page"></iframe> embeds another HTML document inside the current page. Its src selects the document, and title gives the frame an accessible name. Some sites refuse to be embedded, so use a local page when practicing.

A block element usually starts a new line (<div>, <p>); an inline element flows within text (<span>, <a>); a void element has no closing tag or child content (<img>, <br>, <input>).

Chapter 3 · CSS · Slides 7–12

What is a CSS rule, and how can CSS be added to HTML?

Show answer and explanation

A CSS rule has a selector and a declaration block: p { color: blue; font-size: 18px; }. Here p selects paragraphs, color and font-size are properties, and blue and 18px are their values. A declaration ends with a semicolon.

Use external CSS with <link rel="stylesheet" href="style.css"> in the head, internal CSS with a <style> element, or an inline style attribute on one element. The exam may ask you to write the required rules for given HTML.

Chapter 3 · CSS · Slides 17–24

How do basic and attribute selectors match elements?

Show answer and explanation

p selects all paragraph elements; .note selects elements with class note; #intro selects the element with id intro; * selects all elements. h1, h2 groups two selectors. [required] selects elements with that attribute, and input[type="password"] selects password inputs. An element can have several classes separated by spaces.

Chapter 3 · CSS · Slides 25–29

What is the difference between space, >, +, and ~ in CSS selectors?

Show answer and explanation

A B selects every B descendant anywhere inside A. A > B selects only a B that is a direct child of A. A + B selects a B immediately following A as a sibling. A ~ B selects later B siblings of A, even when other siblings occur between them. These symbols describe HTML relationships; > does not mean greater-than in a selector.

Chapter 3 · CSS · Slides 30–38

What is a pseudo-class? How do first-child, last-child, and hover work?

Show answer and explanation

A pseudo-class, written with one colon, matches a state or position. li:first-child matches an li only if it is its parent's first child. li:last-child matches an li only if it is its parent's last child. li:hover matches while a pointing device hovers over the item. ol > li:first-child additionally requires the item to be a direct child of ol.

Chapter 3 · CSS · Slides 39–41

How is a pseudo-element different from a pseudo-class?

Show answer and explanation

A pseudo-class selects an element in a state or structural position, such as a:hover or li:first-child. A pseudo-element, written with two colons, selects or creates a part of an element, such as p::first-line, p::before, or a::after. For ::before or ::after to display generated text, set the content property.

Chapter 3 · CSS · Slides 15–16, 56–59

If CSS rules disagree, which color appears? What does !important do?

Show answer and explanation

First consider origin and importance: an applicable !important declaration generally beats a normal author declaration. Among rules at the same importance level, compare selector specificity: ID (#x) beats class, attribute, or pseudo-class (.x, [type], :hover), which beats an element selector (p). If specificity ties, the later rule in the stylesheet wins. An inline style generally beats normal stylesheet rules, but an applicable important declaration can beat a normal inline style.

Example: if #title { color: blue; }, .note { color: green; }, and p { color: red; } all match the same paragraph, blue wins. If the class rule is .note { color: green !important; }, green wins over the normal ID rule. !important is part of a declaration, not a command to choose a different color.

Chapter 3 · CSS · Slides 43–45

What do common CSS properties control?

Show answer and explanation

color changes text color; background-color changes the background. font-size, font-family, and font-weight change text size, typeface, and weight. text-align aligns inline content within a block. width and height set dimensions. border, padding, and margin control the box edges and spacing. display changes layout behavior.

Chapter 3 · CSS · Slides 47–48

What is the CSS box model?

Show answer and explanation

From inside outward, a box has content, padding, border, and margin. Padding is space between content and border; margin is space outside the border between the element and its neighbors. By default, width sets the content width. With box-sizing: border-box, the declared width includes content, padding, and border.

Chapter 3 · CSS · Slides 49–55

What is the difference between rem, em, %, vw, and vh?

Show answer and explanation

rem is relative to the root (html) font size. em is relative to the current element's computed font size for most properties; when used to set font-size, it is relative to the parent font size. % depends on the property and its reference size. vw is 1% of viewport width; vh is 1% of viewport height. px is a CSS pixel, commonly used as an absolute length unit in this course.

Example: if the root font size is 16px, 2rem is 32px. If a parent has a 20px font size, font-size: 2em on a child is 40px. For “relative to the font size of the root,” choose rem.

How do you put JavaScript in HTML, and is JavaScript case-sensitive?

Show answer and explanation

Place code inside <script> ... </script> or load an external file with <script src="app.js"></script>. Put an external script at the end of the body or use defer when it must wait for HTML parsing. JavaScript is case-sensitive: student and Student name different identifiers. A separate .js file contains JavaScript only, without <script> tags.

Chapter 4 · JavaScript · Slides 14–16

What is the difference between var, let, and const?

Show answer and explanation

var is function-scoped (or global outside a function) and can be redeclared. let is block-scoped and can be reassigned but not redeclared in the same scope. const is block-scoped and must be initialized; its binding cannot be reassigned. A const object or array can still have its contents changed. Prefer let when reassignment is needed and const otherwise.

Chapter 4 · JavaScript · Slides 17–18, 22

What are JavaScript data types, and what does typeof null return?

Show answer and explanation

Primitive types include string, number, boolean, undefined, null, bigint, and symbol. Objects are non-primitive; arrays and functions are object-like values. typeof null returns the string "object" because of a historical JavaScript behavior, even though null is a primitive value. typeof [] also returns "object"; use Array.isArray(value) to identify an array.

Chapter 4 · JavaScript · Slides 23–25

How do JavaScript strings and numbers behave?

Show answer and explanation

Strings are text in single quotes, double quotes, or backticks. Backticks allow interpolation such as Hello, ${name} inside a backtick-delimited string. .length counts string code units; methods such as .toUpperCase() and .slice() return new strings. JavaScript numbers include integers and decimals; arithmetic operators calculate with them. + concatenates when one operand is a string, while - often converts numeric strings to numbers. This explains why 5 + "4" is "54" but 5 - "4" is 1.

Chapter 4 · JavaScript · Slides 19–21

How do you create an object and use properties, methods, and this?

Show answer and explanation

An object groups named properties inside { }, for example let student = { name: "Ali", age: 20 };. Read a property with student.name or student["name"]; update it with student.name = "Sara". A method is a function stored as a property, such as greet: function() { return this.name; }. Called as student.greet(), this refers to that object.

Chapter 4 · JavaScript · Slides 30–33

How do arrays, indexes, and common array methods work?

Show answer and explanation

An array stores an ordered sequence inside [ ], for example let names = ["Ali", "Sara"];. Indexes start at 0: names[0] is "Ali", and names.length is 2. push(x) adds to the end and returns the new length; pop() removes and returns the last item; unshift(x) adds to the start; shift() removes the first item. Arrays can hold objects, such as { name: "Ali" }.

Chapter 4 · JavaScript · Slides 34–37

What does the spread operator (...) do?

Show answer and explanation

Spread expands an iterable, often an array, at the place where values are expected. [...numbers, 4] copies existing array elements into a new array before adding 4. sum(...numbers) passes array items as separate function arguments. {...person} copies an object's enumerable own properties into a new object. [numbers, 4] is different: it inserts the entire array as one nested element. Spread creates a shallow copy.

Chapter 4 · JavaScript · Slides 38–41

How do if/else, switch, and the conditional operator choose a branch?

Show answer and explanation

if (condition) { ... } else { ... } runs one branch based on a truthy or falsy condition. Add else if for more cases. switch (value) compares a value against case labels; break usually stops fall-through to later cases. The ternary operator condition ? valueIfTrue : valueIfFalse chooses one of two expressions.

Chapter 4 · JavaScript · Slides 42–46

How do JavaScript loops differ?

Show answer and explanation

for (initialization; condition; update) repeats while a condition remains true. while (condition) checks before each repetition; do { ... } while (condition) runs the body once before checking. for...of visits values in an iterable such as an array. for...in visits enumerable property keys, often on an object; it is usually not the best way to get array values.

Chapter 4 · JavaScript · Slides 47, 54–56

What is the difference between defining and calling a function?

Show answer and explanation

function add(a, b) { return a + b; } defines a function; add(2, 3) calls it. a and b are parameters in the definition, while 2 and 3 are arguments in the call. return sends a value back to the caller and stops the function. Calling a function with extra arguments does not change its named parameter list; unused extras are ignored unless collected.

Chapter 4 · JavaScript · Slides 48–53, 55

What function forms and nested functions are in scope?

Show answer and explanation

The slides list five forms: (1) a function declaration, function add(a,b) { return a+b; }; (2) an anonymous function expression assigned to a variable, const add = function(a,b) { return a+b; };; (3) a named function expression, const add = function sum(a,b) { return a+b; };; (4) an arrow function, const add = (a,b) => a+b;; and (5) an immediately invoked function expression (IIFE), (function() { console.log("Hi"); })();, which runs as it is defined. A nested function is defined inside another function and can use the outer function's local values.

Chapter 4 · JavaScript · Slides 57–58

What is the difference between rest parameters and spread syntax?

Show answer and explanation

Both use ..., but their locations determine their meanings. In a function definition, function sum(...values), rest collects extra arguments into the array values. In a call, sum(...numbers), spread expands the array numbers into separate arguments. A rest parameter must be the last parameter. In function sum(a, b, ...rest), the first two arguments go to a and b; all remaining arguments go into rest.

What each tag or code part means here

Code question 5

Write a merged-cell HTML table and its CSS

Create a three-column schedule. Row 1 has Schedule spanning all three columns; row 2 has Day, Time, Topic; rows 3–4 show Monday at 9:00 HTML and 10:00 CSS, with Monday spanning both rows. Add borders, padding, and first/last/hover row colors.

Show answer and explanation
Correct code
<table>
  <tr><th colspan="3">Schedule</th></tr>
  <tr><th>Day</th><th>Time</th><th>Topic</th></tr>
  <tr><td rowspan="2">Monday</td><td>9:00</td><td>HTML</td></tr>
  <tr><td>10:00</td><td>CSS</td></tr>
</table>
<style>
  table { border-collapse: collapse; }
  th, td { border: 1px solid black; padding: 8px; }
  tr:first-child { background: navy; color: white; }
  tr:last-child { background: lightyellow; }
  tr:hover { background: lightblue; color: black; }
</style>

What each tag or code part means here

<style>Contains the CSS rules used to style this example.
<table>Contains the entire schedule grid.
<td>Creates a data cell for a value such as Monday or 9:00.
<th>Creates a header cell for a heading such as Day or Time.
<tr>Creates one horizontal table row.
colspanMakes a cell span the specified number of columns.
rowspanMakes a cell span the specified number of rows.
colspan="3"The Schedule header occupies all three columns of its row.
rowspan="2"The Monday cell occupies two rows, so the last row starts with Time.
border-collapseCombines adjacent table borders into single lines.
borderDraws the border around each header and data cell.
paddingAdds space inside each cell.
tr:first-childColors the first row, which contains Schedule.
tr:last-childColors the final data row.
tr:hoverApplies hover colors to whichever row the pointer is over.
background / colorSet a row's background and text colors.
Step-by-step explanation
Think of a three-column grid. colspan fills all three positions in row 1. rowspan occupies Monday's position in two rows, so row 4 contains only 10:00 and CSS. The CSS gives every cell a border and internal spacing, then applies the requested pseudo-classes to rows.
Code question 6

Create a course object, students array, and addStudent method

Start with two student objects, add a third student's name through a method, and return the new number of students.

Show answer and explanation
Correct code and output
let course = {
  title: "Web Applications",
  students: [{ name: "Ali" }, { name: "Sara" }],
  addStudent: function(name) {
    this.students.push({ name: name });
    return this.students.length;
  }
};
console.log(course.addStudent("Omar")); // 3
console.log(course.students[2].name);   // Omar

What each tag or code part means here

let course = { ... }Creates the course object and stores it in a variable.
title: "Web Applications"Stores the course title as a string property.
students: [ ... ]Stores an array of two initial student objects.
{ name: "Ali" }One student object with a name property; Sara has the same shape.
addStudent: function(name)Defines a method that receives the new student's name.
this.studentsAccesses this course object's students array during course.addStudent(...).
push({ name: name })Adds a new student object to the array's end.
return this.students.lengthReturns the array length after the insertion.
course.addStudent("Omar")Calls the method and passes Omar as its argument.
course.students[2].nameReads the third student's name, since array indexes start at zero.
console.logPrints the returned count and the added name.
Step-by-step explanation
The initial array has two objects. Calling addStudent pushes { name: 'Omar' }, making its length 3. The method returns 3, and index 2 contains Omar. This is the object-and-array coding pattern described by the doctor.
Code question 7

Find the output: function, array, rest, and spread

Write the console output in order.

Given code
function sum(a, b, ...rest) {
  let result = a + b;
  for (let n of rest) { result += n; }
  return result;
}
let arr = [2, 4, 6];
console.log(sum(...arr));
console.log(sum(2, 4));
function first(a, b) { return a + b; }
console.log(first(...arr));
Show answer and explanation
Output
12
6
6

What each tag or code part means here

function sum(a, b, ...rest)Defines sum with two named parameters; rest collects later arguments into an array.
let result = a + bStarts the total with the first two values.
for (let n of rest)Visits each remaining value collected in rest.
result += nAdds the current value to the running total.
return resultSends the completed total back to the caller.
let arr = [2, 4, 6]Creates an array of three numbers.
sum(...arr)Spread passes 2, 4, and 6 as separate arguments, producing 12.
sum(2, 4)Calls sum with no extra arguments, producing 6.
function first(a, b)Defines a function that uses only its first two arguments.
first(...arr)Passes three arguments, but first ignores the third and returns 6.
console.logPrints each returned result on a new line.
Step-by-step explanation
In sum(...arr), spread turns the array into three arguments; a=2, b=4, and rest=[6], so the result is 12. sum(2,4) has an empty rest array and returns 6. first(...arr) receives three arguments but uses only 2 and 4, so it returns 6.

Code question 9

Find the output: scope and a nested function

Write the console output in order. This extra example stays within the function and rest-parameter slides.

Given code
let x = 1;
if (true) { let x = 9; console.log(x); }
function total(...a) {
  function twice(n) { return n * 2; }
  let s = 0;
  for (let v of a) { s += twice(v); }
  return s;
}
console.log(x);
console.log(total(1, 2));
Show answer and explanation
Output
9
1
6

What each tag or code part means here

let x = 1Creates the outer x.
if (true) { let x = 9; ... }Runs the block and creates a separate block-scoped x.
function total(...a)Defines total; its rest parameter collects the arguments into array a.
function twice(n)Defines a nested function that doubles one number.
let s = 0Starts the running sum.
for (let v of a)Visits each collected argument value.
s += twice(v)Doubles the current value and adds it to the sum.
return sReturns the completed sum to the caller.
console.logPrints the block x, the outer x, and the function result.
total(1, 2)Collects [1,2], doubles each, and returns 2+4=6.
Step-by-step explanation
The inner let x shadows the outer x, so the first output is 9 and the second is 1. total(1,2) collects both arguments; twice returns 2 and 4; their sum is 6.
